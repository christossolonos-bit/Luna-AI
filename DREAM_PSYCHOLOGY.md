
## 🔬 **How It Works**

### **Experience Collection**
Every conversation is analyzed for:
- **Emotional Impact**: Base 0.3, +0.3 for emotional content, +0.2 for relationship content
- **Problem Relevance**: Detected through keywords like 'problem', 'issue', 'help', 'solve'
- **Memory Importance**: Based on conversation significance

### **Dream Generation Process**
```
1. Experience Added → Dream Processing Queue
2. Sleep Cycle Started → 90-minute cycle begins
3. NREM Stages → Memory consolidation
4. REM Stage → Emotional processing & creative dreams
5. Dreams Generated → Ollama creates symbolic content
6. Processing Complete → Emotions reduced, memories strengthened
```

### **Dream Database**
All dreams are stored with:
- **Content**: Full dream narrative
- **Type**: Emotional, creative, memory, relationship
- **Metrics**: Intensity, vividness, coherence
- **Themes**: Emotional themes, memory connections
- **Sleep Stage**: NREM1/2/3 or REM

## 📊 **Dream Metrics**

### **Intensity** (0.0 - 1.0)

### **Vividness** (0.0 - 1.0)
- How clear and detailed the dream is
- Random range based on sleep stage
- Higher in REM sleep

### **Coherence** (0.0 - 1.0)
- How logical and connected the dream is
- Memory dreams: 0.8-1.0 (high coherence)
- Creative dreams: 0.5-0.8 (lower coherence, more abstract)

## 🚀 **Technical Implementation**

### **Database Schema**
```sql
-- Dreams table
CREATE TABLE dreams (
    id INTEGER PRIMARY KEY,
    timestamp REAL,
    sleep_stage TEXT,
    dream_type TEXT,
    content TEXT,
    emotional_themes TEXT,
    memory_connections TEXT,
    creative_insights TEXT,
    intensity REAL,
    vividness REAL,
    coherence REAL,
    processing_complete BOOLEAN
);

-- Sleep cycles table
CREATE TABLE sleep_cycles (
    id INTEGER PRIMARY KEY,
    cycle_number INTEGER,
    start_time REAL,
    end_time REAL,
    stages TEXT,
    memory_consolidation TEXT,
    emotional_processing TEXT,
    cycle_complete BOOLEAN
);
```

### **Threading Architecture**
- **Sleep Worker Thread**: Handles 90-minute sleep cycles
- **Dream Generation**: Uses Ollama for dream content creation
- **Database Operations**: Async dream and cycle storage
- **Integration**: Non-blocking experience collection
